# Differentiator refinement — architectural reveal

## Message

The differentiator is the enterprise system connected around the agent:
business-owned knowledge, reusable expert methods, controlled data access and
improvement grounded in execution evidence. The same reasoning-and-tool capability
remains at the centre throughout the reveal.

This treatment selects the architectural cutaway from the supplied advice and
adapts it to v3's established paper, method and provenance objects. It presents
the enterprise system as a set of concrete additions to a capable agent.
